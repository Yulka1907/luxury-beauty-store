BeautyShop — премиальный интернет‑магазин косметики

Премиальный мини‑интернет‑магазин в стиле Luxury Gold UI, созданный для портфолио. 
Содержит каталог товаров, корзину, карточки товаров, оформление заказа, страницу профиля и страницу «Спасибо за заказ».

✨ Функционал

- Каталог товаров 
- Карточки товаров 
- Добавление в корзину 
- Корзина с подсчётом суммы 
- Оформление заказа 
- Страница «Спасибо за заказ» 
- Профиль пользователя (localStorage) 
- Полностью адаптивный дизайн 
- Премиальный стиль интерфейса 

🛠 Технологии

- HTML 
- CSS 
- JavaScript 
- LocalStorage 
- GitHub Pages
